description: Final reporting and regression guidance phase.
---

1. Produce final findings list from `confirmed` vulnerabilities only.
2. For each finding, include:
- affected path and location
- reproducible evidence summary
- root cause
- remediation guidance
- variant status
3. Provide regression test guidance (unit/integration/fuzz) per vulnerability class.
4. Flag unresolved `inconclusive` items separately as follow-up work.
5. Summarize residual risk and recommended next hardening tasks.
